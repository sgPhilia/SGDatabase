# SGDatabase / LearnDatabase Project Summary

SGDatabase is the repository for LearnDatabase, a progressive university-level database engineering textbook collection pairing systems theory with practical study and a staged Rust implementation track. The scope baseline contains 13 volumes. Chapter-level IDs currently exist only for Volume I; the remaining volumes are topic outlines, not an exact chapter count.

The repository includes the Master Prompt, an eight-page research synthesis PDF, six foundational chapter files, a 34-record research index and curriculum map, a 13-volume dependency matrix, chapter acceptance and lab standards, and detailed specifications for the existing 22 implementation milestones. The PDF is a topic map, not a verified bibliography; see `RESEARCH.md`. No engine code, build/test configuration, or standalone lab directory currently exists; assessed exercises and labs are embedded in chapters.

For authoritative status, use `ROADMAP.md` for planned scope, `CHAPTER_STATUS.md` for per-chapter status, `PROGRESS.md` for phase/workstream status, `PROJECT_STATE.md` for derived counts, and `QUALITY_REPORT.md` for check evidence. Phase B is complete and Phase C chapter development is in progress; C02–C04 are accepted, while C01 and C05 have open diagram validation items. See `SESSION_HANDOFF.md` for the exact task.
