# SGDatabase / LearnDatabase Project Summary

SGDatabase is the repository for LearnDatabase, a progressive university-level database engineering textbook collection pairing deep systems theory with practical study and staged Rust implementations. Scope runs from data and computing foundations through relational modeling, SQL, architecture, storage, indexes, query processing, transactions, recovery, distributed systems, advanced engineering, and real-system studies. Complex domains may require multiple chapters.

The initial assessment found the Master Prompt and one eight-page AI-generated research synthesis PDF; no curriculum or implementation existed then. Git history now exists. The latest repository inspection found a clean `main` branch with two commits and no implementation tree. The PDF offers a useful topic map, but its bibliography is incomplete. See [RESEARCH.md](RESEARCH.md) for evidence limits and verification policy.

The multi-volume architecture and chapter hierarchy are in [ROADMAP.md](ROADMAP.md); chapter-level status is in [CHAPTER_STATUS.md](CHAPTER_STATUS.md). Resume instructions are in [AI_CONTEXT.md](AI_CONTEXT.md) and [SESSION_HANDOFF.md](SESSION_HANDOFF.md). Volume I is underway; implementation milestones have not started.
