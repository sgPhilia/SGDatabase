# LearnDatabase Project Summary

LearnDatabase is a progressive, university-level database engineering textbook collection that pairs deep systems theory with practical study and staged Rust implementations. Its scope runs from data, computer, and database foundations through relational modeling, SQL, architecture, storage, indexes, query execution, transactions, recovery, distributed databases, advanced engineering, and verified studies of real systems. Complex domains may require multiple chapters.

The initial repository assessment found only the Master Prompt and a single eight-page AI-generated research synthesis PDF. No curriculum, source tree, implementation, or usable Git metadata was present. The PDF offers a useful domain map and pedagogical direction, but its bibliography is incomplete and several claims need primary-source verification. See [RESEARCH.md](RESEARCH.md) for evidence limits and the verification policy.

The multi-volume architecture, detailed chapter hierarchy, scope estimate, and completion standard are in [ROADMAP.md](ROADMAP.md). Current statuses are in [PROGRESS.md](PROGRESS.md). The first chapter begins Volume I at the absolute fundamentals. Remaining chapters and all database implementation milestones are unstarted.
