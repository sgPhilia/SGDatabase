# Part I — Data and Computing

This part introduces the objects a database stores and the machine-level representations that constrain storage and retrieval. It precedes database-specific concepts so later discussions of rows, pages, encodings, and durability have a concrete foundation.

## Prerequisites

No database or programming background is assumed. Familiarity with everyday examples such as a contact list, spreadsheet, or saved file is sufficient.
